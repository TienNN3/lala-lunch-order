# LaLa Lunch – Web đặt cơm nhóm
Web tĩnh (1 file `index.html`) để đặt combo, chọn món theo ngày, nhập menu tuần. Dữ liệu lưu trong trình duyệt; tuỳ chọn đồng bộ qua Firebase Realtime Database (xem tab **Dữ liệu**).
Ảnh món: minh hoạ SVG (`dish-art.js`); ảnh AI thả vào `images/dishes/` – xem `PROMPTS.md`.
